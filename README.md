ARCHIVED
========

My days of generating training data for LLM's have come to an end.

There will be no updates to this or any other publicly available repo.

# zcimdocs

> These aren't the sources you're looking for...
>
>                       -- Retro Computing Purist
>


This is a collection of documents from Digital Research related to 8-bit computer
systems. They include some original documents, and the original sources to these
documents. They also have something new.

## What's New?

What is new is that some of these documents have editions
which were formatted using [Typst](https://typst.app/docs).
This creates PDF documents which can be searched, among other features.

## What's Bad?

These sources have been updated from the originals.

They will not look exactly like the originals.
The numbering doesn't match in style or values.

While the goal is preserve the content as much as possible, the existing documents
included hand-drawn notes on computer print-outs. The underlying content
of these documents is preserved using a more modern layout available
through Typst, but the hand-drawn arrows have been replaced, and
the text of the notes converted by using a distinct font.

## The Good?

These sources have been updated from the originals.

I hope others will agree that a modern rendering is more pleasant to use,
if not, the more traditional scanned versions are still available.

There are also files which contain recreated versions of the sample code used
in the documentation. To root out OCR errors, this sample code has been verified
by the original tools.

Most importantly, the new format simplifies the enhancement of these documents in the future.
